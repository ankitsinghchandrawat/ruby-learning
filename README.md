# sales Tax Application using Ruby

## Description
This is a Ruby-based application that calculates sales tax and generates a receipt for a list of items.

## Featurs
* 10% basic sales tax (except books, food, medical)
* 5% import duty (on all imported goods)
* Round tax to nearest 0.05
* receipt generation

## Project Structure
* Item -> represents a product
* Taxcalculator -> calculates tax
* Receipt -> generates final bill

## How  to Run 
ruby main.rb

## Approach
Used Object-Oriented Programming :
* Item class for data
* TaxCalculator for tax logic
* Receipt for output formatting
